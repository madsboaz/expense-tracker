# Personal Expense Tracker

The Personal Expense Tracker is a simple command-line application designed to help you manage your expenses effortlessly. Built using Python, this tool allows users to record, organize, and analyze their spending habits with ease. With features such as adding new expenses, viewing recorded data, generating category-wise expense reports, and exporting to CSV, this tracker is a straightforward solution for personal finance management.

Users can categorize their expenses into predefined categories like Food, Transportation, Utilities, Entertainment, and Other, ensuring their spending is well-organized. The application includes convenient options like automatically using the current date for new expenses if one is not specified. Thoughtful error handling and a user-friendly menu system make it easy to use, even for beginners.

The tracker also supports generating summary reports, which provide insights into total spending across categories. For those who need to analyze their data further or back it up, the tool allows exporting all recorded expenses to a CSV file with just a few clicks.

This program requires Python 3.6 or later to run. Simply execute the script in your terminal and follow the on-screen prompts to begin managing your expenses.
